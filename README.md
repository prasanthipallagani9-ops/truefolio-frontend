
# TRUEFOLIO
### Make Every Activity Count.

A Student Development Intelligence Platform.

## Project Overview

TRUEFOLIO aims to bridge the visibility gap between students and faculty by providing a structured platform to record, manage and review student development activities.

Students can maintain records of their achievements, projects and activities with supporting evidence. Faculty members can review submitted activities and provide decisions and feedback.

## Problem Being Addressed

Student achievements are often distributed across different platforms, certificates, documents and personal records. Faculty may not have a consolidated view of student development.

TRUEFOLIO proposes a centralized system for documenting and reviewing these activities.

## Main Features

### Student Module
- Student dashboard
- Activity management
- Evidence management
- Project portfolio
- Student profile

### Faculty Module
- Faculty dashboard
- Activity review queue
- Assigned student directory
- Student development dossiers
- Review decisions and feedback

## Deployment

Frontend demo: https://truefolio.onrender.com

## Running the Frontend Locally

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```

## Current Implementation Status

TRUEFOLIO is currently a deployed interactive frontend prototype.

The frontend uses seeded demo data and browser localStorage for demonstration. Live authentication, shared database integration, cloud evidence storage and complete application backend APIs are not yet connected.

The Express backend currently provides a basic health-check endpoint.
